Manifesto / Metodo

FUORISCALA è uno studio indipendente italiano fondato su un’idea semplice: la dimensione del team non deve determinare quella dell’ambizione. Progettiamo giochi leggibili, profondi e riconoscibili, senza fingere di essere più grandi di ciò che siamo.

01ProgettatoOgni elemento deve avere una ragione per esistere.
02DirettoNiente linguaggio aziendale finto o promesse vuote.
03AutorialeOgni progetto deve conservare una personalità propria.
04Fuori misuraIl formato non deve diventare un limite creativo.
